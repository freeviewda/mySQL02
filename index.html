SQL JOIN 완벽 정리: INNER, LEFT, 그리고 WHERE

데이터베이스에서 두 개의 테이블을 연결할 때 사용하는 JOIN! 헷갈리기 쉬운 개념과 실습 예제를 깔끔하게 정리해 보았습니다.

🤝 1. INNER JOIN (교집합)

JOIN은 서로 관련 있는 두 테이블을 이어 붙이는 기능입니다. 보통 한쪽의 PK(기본키)와 다른 쪽의 FK(외래키)를 기준으로 연결합니다.

💡 이해하기 쉬운 예시
Table_A: id 1, 2, 3
Table_B: a_id 1, 2, 4
이때 두 테이블을 연결하면 둘 다 가지고 있는 값인 1, 2만 결과에 남습니다.
📌 핵심 요약
INNER JOIN = 두 테이블에서 서로 매칭되는 행만 가져오는 것 (교집합)

💻 실습 1) 입원한 적 있는 환자의 정보만 조회하기

SELECT * FROM patients INNER JOIN admissions ON patients.patient_id = admissions.patient_id;

💻 실습 2) 실제로 입원하고, 담당 의사가 배정된 환자의 정보 조회

SELECT patients.last_name, admissions.diagnosis, doctors.specialty FROM patients INNER JOIN admissions ON patients.patient_id = admissions.patient_id INNER JOIN doctors ON doctors.doctor_id = admissions.attending_doctor_id;

👈 2. LEFT JOIN (기준은 왼쪽!)

LEFT JOIN은 왼쪽 테이블의 데이터는 무조건 다 가져오고, 오른쪽 테이블에 같은 값이 있으면 붙이고 없으면 비워 두는(NULL) 방식입니다.

📌 핵심 요약
왼쪽(A)에 있는 행은 절대 사라지지 않음!
오른쪽(B)은 맞는 데이터가 있을 때만 붙고, 없으면 NULL로 표시됨.

💻 실습 1) '모든 환자'의 입원 정보 조회 (입원 안 한 환자 포함)

SELECT patients.patient_id, admissions.admission_date FROM patients LEFT JOIN admissions ON patients.patient_id = admissions.patient_id;

🔍 3. JOIN + WHERE (필터링 추가)

먼저 JOIN으로 테이블을 연결한 다음, WHERE 조건절로 필터링하는 방식입니다. 연결 기준(ON)을 세운 후, 연결된 결과에서 필터링(WHERE)을 거친다고 생각하면 쉽습니다.

💻 실습) 모든 환자의 정보 중 province_id = 'AB'인 환자만 조회

SELECT patients.patient_id, province_names.province_name FROM patients LEFT JOIN province_names ON patients.province_id = province_names.province_id WHERE patients.province_id = 'AB';
